# Smart Python Chatbot

A simple chatbot created using Python.

## Features
- Greeting responses
- Date and time feature
- Joke command
- Help command
- Exit system

## Concepts Used
- if-else
- Loops
- datetime module
- String handling

## How to Run
1. Install Python
2. Run:
python smart_chatbot.py

## Output
Chatbot interacts with user in terminal.
